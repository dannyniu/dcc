2026-04-12, Roles of Each Files:
====

`cpp-ctrlline-*`:
----

Implement the behaviors of preprocessing directives,

`cpp-master.*`:
----

Watches for and invokes preprocessing directives,
optionally suppressing the lines skipped by conditional inclusions.

In the final stage of emitting tokens, it coalesces string literals, and
looks up the (partial) parse tree for typenames. (TODO as of 2026-07-24.)

`cpp-macro-expand.c`:
----

Handles the expansion of macros, by intercepting the token shifter of
the unprocessed source code file, and produce a stream of processed tokens.
Due to requirements on rescanning, the actual implementation detail is complex,
in short, it consist of a scanning recursion and a macro expander that invokes
each other.

`cpp-macro-expand-special.c`
----

Deals with special preprocessing predicates/functions that're provided by the
preprocessor - i.e. that're not definable by user code.
